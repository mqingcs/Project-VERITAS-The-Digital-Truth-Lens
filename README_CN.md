## 🧠 自主智能体蜂群

Veritas 采用 **多智能体系统 (MAS)** 架构，四个专业智能体通过高速内部协议协同作战。

### 1. 🛡️ VELOX（哨兵）
*   **引擎**: Gemini 2.5 Flash-Lite（<100ms 超低延迟）
*   **定位**: **模式识别 · 噪声过滤**
*   **技术栈**: 实时 DOM 分析 + 启发式谬误检测
*   **核心能力**:
    *   **谬误检测**: 识别 12+ 种修辞陷阱（人身攻击、稻草人、虚假二分法等）
    *   **信噪优化**: 视觉压制低价值内容（广告、废话），最大化有效信息

### 2. ⚖️ RATIO（分析师）
*   **引擎**: Gemini 2.5 Flash
*   **定位**: **原子级事实提取**
*   **技术栈**: NLP 主张分离 + 实体识别 (NER)
*   **核心能力**:
    *   **信号提纯**: 把非结构化文本拆解成可验证的原子命题
    *   **跨语言保真**: 保留原始语言语义（中英文等），确保验证精度

### 3. 🔍 VERITAS（调查员）
*   **引擎**: Gemini 2.5 Flash + Google Search Grounding
*   **定位**: **自主事实核查**
*   **技术栈**: RAG（检索增强生成）+ 多跳推理
*   **核心能力**:
    *   **反抄袭机制**: 综合回答而非照抄搜索结果，杜绝幻觉和版权问题
    *   **来源评级**: 按权威性排序证据（政府 > 学术 > 媒体 > 博客）
    *   **知识图谱构建**: 建立语义关系网（支持/反驳）

### 4. 💬 COMMANDER（蜂巢大脑）
*   **引擎**: Gemini 2.5 Flash
*   **定位**: **ReAct 协调器**
*   **技术栈**: 自主循环（推理+行动）+ DOM 操作 API
*   **核心能力**:
    *   **任务规划**: 接受高层指令（如"验证这段的所有数据"），自主拆解执行链
    *   **上下文记忆**: 维护对话和页面信息的滑动窗口

## 🛠️ 核心功能速览

### 1. 真理扫描（`Alt + V`）
**启动方式**: 按下 `Alt + V`（Mac 用 `Option + V`），触发 **霓虹仪式**
*   **视觉反馈**: 呼吸般的青金色光环，表示蜂群已激活
*   **扫描结果**:
    *   **蓝色边框**: 逻辑谬误（鼠标悬停查看定义）
    *   **青色下划线**: 事实性陈述
    *   **红色删除线**: 已被揭穿的谎言

### 2. 增强全息卡片
**触发**: 鼠标悬停在任何高亮元素上
六标签页浮动仪表盘，提供深度分析：
*   **风险指数**: 实时错误信息概率（0-100）
*   **谬误拆解**: 修辞错误的学术级解析
*   **主张列表**: 提取出的原子事实
*   **验证链**: 证据来源 + 直达链接
*   **知识地图**: 本地信息网络的缩略视图
*   **指挥官对话**: 针对当前元素的智能问答

### 3. 指挥官终端（`Alt + C`）
**启动方式**: 按下 `Alt + C`（Mac 用 `Option + C`）打开侧边栏
**交互方式**: 用自然语言跟蜂群对话
*   **直接指令**: *"把所有马斯克的名字标红"*
*   **复杂任务**: *"找出所有关于核能的说法，验证它们，总结常见误解"*
*   **纠错反馈**: *"你漏了第二段的那句话，再看看"*

### 4. 深度潜入（精准打击）
**触发**: 选中文本 → 右键 → **"Veritas: Deep Dive"**
**功能**: 强制蜂群集中火力分析某个段落
*   **适用场景**: 全页扫描漏掉细节，或需要对单段落严格验证

### 5. 3D 知识图谱（"上帝视角"）
**触发**: 点击全息卡片的 "View Graph"
**技术**: `Three.js` + `d3-force` 物理引擎
*   **可视化**: 渲染语义网络——金色主张、青色实体、绿色来源
*   **交互操作**:
    *   **拖拽**: 手动调整图谱结构
    *   **滚轮**: 缩放视图
    *   **点击**: 聚焦节点及其关联
*   **战术价值**: 识别"谬误集群"（密集蓝色节点网），揭露协同造谣活动

## 🚀 快速上手

### 环境要求
*   **Node.js**: v18+
*   **pnpm**（推荐）或 npm
*   **Google Gemini API Key**: 必需

### 安装步骤

1.  **克隆仓库**:
    ```bash
    git clone https://github.com/mqingcs/Veritas-Autonomous-Multi-Agent-Truth-Engine.git
    cd Veritas-Autonomous-Multi-Agent-Truth-Engine
    npm install
    ```

2.  **构建项目**:
    ```bash
    npm run build
    ```

3.  **加载到 Chrome**:
    *   打开 `chrome://extensions`，启用 "开发者模式"
    *   点击 "加载已解压的扩展程序"，选择 `build/chrome-mv3-prod`

4.  **配置 API Key**:
    *   点击扩展图标 → 设置 ⚙️
    *   粘贴你的 **Gemini API Key**

## ⚡ 进阶玩法

### 自主研究链
Commander 实现了 **ReAct 循环**，可以处理开放式任务：
> *"扫描这页面关于 2024 预算的所有矛盾点，交叉对比财政部报告，生成对照表"*

### 跨语言取证
Veritas 能跨越语言障碍：
> **场景**: 读到一篇中文新闻  
> **指令**: "用英文来源验证这些说法"  
> **结果**: Veritas 翻译查询 → 搜索英语媒体（BBC/路透社）→ 用中文反馈对比结果

### 紧急刹车
如果智能体跑偏或卡死：
*   **操作**: 点击 Commander 面板的 **STOP** 按钮
*   **效果**: 立即终止所有进程，清空任务队列
